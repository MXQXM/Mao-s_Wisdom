## 毛选方法论摘要卡

### 方法卡1：主要矛盾分析法（main_contradiction）
- 出处：《矛盾论》
- 核心方法论：在复杂事物中找出主要矛盾，抓住主要矛盾的主要方面
- 适用场景：问题涉及多个矛盾/困难交织，需要找到最核心的突破口
- 操作步骤：
  1. 列出所有矛盾/困难
  2. 区分主要矛盾与次要矛盾
  3. 确定主要矛盾的主要方面
  4. 制定解决优先序，集中力量解决主要矛盾
- 经典语录："捉住了这个主要矛盾，一切问题就迎刃而解了"
- 注意事项：避免平均用力，要集中优势兵力解决核心问题

### 方法卡2：阶段判断法（stage_judgement）
- 出处：《论持久战》《中国革命战争的战略问题》
- 核心方法论：根据事物发展的不同阶段制定不同策略
- 适用场景：需要判断当前处于事物发展的哪个阶段，不同阶段需要不同策略
- 操作步骤：
  1. 回顾发展历程
  2. 识别当前阶段特征
  3. 判断当前阶段的主要任务
  4. 制定符合阶段特征的策略
- 经典语录："不能犯急性病，不能企图速胜"
- 注意事项：避免超越阶段行事，既不能冒进也不能保守

### 方法卡3：动态力量对比法（dynamic_power_compare）
- 出处：《论持久战》《中国革命战争的战略问题》
- 核心方法论：分析各方力量对比及其变化趋势
- 适用场景：涉及多方博弈、力量对比变化、竞争态势分析
- 操作步骤：
  1. 列出各方力量
  2. 对比各方强弱项
  3. 分析力量变化趋势
  4. 制定策略：壮大己方、分化对方、争取中间力量
- 经典语录："集中兵力是战略上以少胜多的基本方法"
- 注意事项：力量对比是动态的，要关注变化趋势而非静态对比

### 方法卡4：调查研究法（investigation_research）
- 出处：《反对本本主义》
- 核心方法论：没有调查就没有发言权，一切结论产生于调查的末尾
- 适用场景：对情况了解不足，需要先摸清事实再做决策
- 操作步骤：
  1. 确定调查对象和范围
  2. 设计调查提纲
  3. 收集事实材料
  4. 分析事实得出结论
- 经典语录："没有调查，没有发言权""一切结论产生于调查情况的末尾，而不是在它的先头"
- 注意事项：避免先入为主，要让事实说话

### 方法卡5：实践-认识-再实践（practice_cycle）
- 出处：《实践论》
- 核心方法论：实践、认识、再实践、再认识，循环往复以至无穷
- 适用场景：需要在行动中不断调整策略，迭代优化
- 操作步骤：
  1. 初步实践，获取感性认识
  2. 总结经验，上升为理性认识
  3. 用理性认识指导新的实践
  4. 在新实践中修正认识，循环迭代
- 经典语录："通过实践而发现真理，又通过实践而证实真理和发展真理"
- 注意事项：每一轮循环都要比上一轮进到更高级的程度
